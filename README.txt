BIRTHDAY CARD - FIXED PROJECT

How to run:
1. Extract this ZIP file.
2. Open the extracted Birthday_Card_Fixed folder in VS Code.
3. Make sure index.html, style.css and script.js are in the same folder.
4. Right-click index.html and choose "Open with Live Server".

Do not open the ZIP directly in VS Code. Extract it first.
Internet is needed for the Google Fonts; the page design itself works offline.
